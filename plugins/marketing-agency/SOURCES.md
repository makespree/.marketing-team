# Sources and reuse

Researched 2026-09-27. This package is authored for reuse across products. No brand
identity, customer records, artwork, cloud settings or private conversation is bundled.

## Adapted open-source skills

Six skills are condensed adaptations of [Corey Haines' marketingskills](https://github.com/coreyhaines31/marketingskills),
at commit `5b2c0007766c6a1cf1d53fd8fc73e979e0821022`:

| Upstream skill | Local skill |
|---|---|
| product-marketing | agency-product-marketing |
| customer-research | agency-customer-research |
| launch | agency-launch |
| copywriting | agency-copywriting |
| content-strategy | agency-content-strategy |
| analytics | agency-analytics |

Retained methods include product context, alternative-based positioning, customer
language, channel sequencing, clear copy, searchable/shareable content and measured
experiments. Adaptations use one project vault, support product types beyond SaaS,
separate facts from hypotheses, and leave public actions within session authority.
Unbundled references, provider commands, fixed ratios, example statistics and
universal launch-channel assumptions were removed. These are not verbatim originals.

The [MIT copyright and permission notice](licenses/corey-haines-MIT.txt) travels
with every clean export and plugin. [sources.lock.json](sources.lock.json) records
exact source URLs, original file hashes and current adapted-file hashes. Original
downloads are retained only in this standalone workspace's private research scratch.
When modifying an adaptation, review the change and deliberately update its lock hash.

No upstream scripts, hooks, network tools or full skill repository are installed.
The Director, reference-restage, visual-production and content-review skills, role
briefs, templates and Python helpers were authored for this package.

## Expert references

The profiles cite evidence and label our proposed agency methods as interpretation.
They are not replicas, endorsements or claims about someone's private thinking.
No expert's campaign art or long excerpts are redistributed.

| Lens | Evidence | Used for |
|---|---|---|
| Steve Jobs | [Apple's original iPhone announcement](https://www.apple.com/newsroom/2007/01/09Apple-Reinvents-the-Phone-with-iPhone/) | Clear product framing and demonstration |
| April Dunford | [The No Differentiation Illusion](https://aprildunford.substack.com/p/the-no-differentiation-illusion) | Alternatives, context and differentiated value |
| Piyush Pandey | [Ogilvy's Lotus Legend profile](https://www.ogilvy.com/ap/ideas/piyush-pandey-bestowed-lotus-legend-award) | Human observation and cultural specificity |
| Paula Scher | [Pentagram profile and work](https://www.pentagram.com/about/paula-scher) | Expressive typography and coherent identity |
| Teresa Torres | [Getting started with discovery](https://www.producttalk.org/getting-started-with-discovery/) | Evidence-led customer understanding |
| Saul and Elaine Bass | [Academy collection](https://www.oscars.org/film-archive/collections/saul-bass-collection), [Elaine's credited work](https://www.artofthetitle.com/designer/elaine-bass/) | Visual motifs, story and motion |
| Les Binet and Peter Field | [IPA research presentation](https://ipa.co.uk/knowledge/documents/the-long-and-the-short-of-it-presentation) | Brand building versus immediate response |

The quality reviewer uses authored production practices; no celebrity authority is
attached to a technical or creative pass. Each role's profile links its detailed lens.

## First-party review runtime
The optional Firebase review studio reuses the owner’s existing standalone
marketing application. runtimes/review-studio/UPSTREAM.json records the source
commit, per-file hashes and deliberate adaptations. No prior product data,
branding guides, Firebase configuration or credentials are included. Runtime
dependency versions and licenses remain governed by its npm lockfile.
