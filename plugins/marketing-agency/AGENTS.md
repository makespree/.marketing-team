# Portable marketing agency
For marketing work, read START.md and skills/agency-director/SKILL.md.
The active project's .marketing/vault is the only project-memory location.
A plugin's bundled instructions are read-only; never write project data into its cache.
Honor the user's requested stage. Planning is not production authorization.
Use only relevant specialist profiles and skills. Native subagents may be used
when the host permits them; otherwise perform the roles sequentially and say so.
No cloud configuration, brand, paid tool or channel authority is inherited by copying
this folder. Existing session authorization remains valid within its exact scope.
