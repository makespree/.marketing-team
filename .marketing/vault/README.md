# Project vault
This directory is project-specific and ignored by Git apart from this guide.
Initialize with scripts/agency.py init. The Director maintains product/context.md,
brand/guidelines.md, decisions/log.md, research/, artwork/, jobs/ and results/.
Artwork records point to real files and preserve prompts, versions, provenance,
usage scope and approval. No media has been generated for this reusable kit.
Backup or external review uses the destination explicitly configured for this
project and only the selected job's files. No whole-vault upload is implicit.
