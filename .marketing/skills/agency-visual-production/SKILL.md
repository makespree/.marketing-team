# Visual production

Read project context, brand decisions and the job's selected direction.
Use the available image-generation/editing skill and renderer appropriate to the
task. A brief without an actual available engine is not a generated deliverable.

## Art direction first
Write the one message, hero, intended response and reference roles. Establish a
coherent type hierarchy, palette, image language, material, density and brand
presence. Choose these for this product; maximalism, minimalism and paper collage
are options, not universal defaults. Specify fonts and usage rights, not only
adjectives such as "premium".

For a carousel, assign one job per slide and a reason to swipe. Design the entire
sequence before extending a cover. Test the longest text and varying image shapes.
For a campaign, distinguish stable visual grammar from new art required for each story.
Reuse approved assets when they fit; never substitute convenient old art for the new idea.

## Asset and generation briefs
List exact-copy assets, subjects/props to generate, real photos to source, and layout
text. Keep logo/identity and documentary assets exact where required. Include:
composition, subject action, material/light, palette, crop, copy/safe areas, forbidden
changes, references and pass conditions. For people, specify what each visible hand
does and check anatomy after generation. Don't convert a representation choice
from one project into a rule for all people in every project.
Record prompts, source inputs, tool/model if known, output versions and approval.

Inspect the image itself. Check spelling, product identity, silhouette, hands/limbs,
contact with the ground, transparency and unwanted marks. Use native exact layout
for critical text/logos when generation cannot reliably preserve them. Only use
editing tools allowed by the current image workflow.

## Layout and review
Check full resolution and phone-size legibility. Inspect line breaks, contrast,
crop, footer boundaries, caption lengths, safe areas and the complete sequence.
For a supplied reference, evaluate the requested relationships rather than merely
reusing its colours. A technical export pass is insufficient.
Start with a representative sample before bulk generation when the direction is
unproven; respect the user's explicit authorized batch if already settled.
Budget/time/tool constraints live in the brief. Paid generation requires its actual
authorization; no automatic retries after an uncertain paid submission.

Save editable sources, final ordered images, caption, alt text, credits, prompts
and review notes in the job. Promote approved reusable assets to artwork/index.json.
